# Normative provenance file for `deliverable-packaging` (spec R5, design
# "Pinned artifacts" table). `package.sh` stage 0 READS this file: every
# Windows input MUST be in the local cache with a matching SHA-256 BEFORE it
# is ever used (R5.1: mismatch => reject, exit 2). Default runs are OFFLINE
# (R5.2): nothing is downloaded unless `--fetch` is passed, in which case the
# URL below is curled into `dest` and re-verified. A valid cache => zero
# network, idempotent skip.
#
# Format is script-parseable: one artifact per line, fields separated by '|',
# in fixed order:
#   sha256|size_bytes|url|dest
# `dest` is relative to $DELIVERABLE_CACHE (default ~/.cache/gentle-deliverable).
# Lines starting with '#' and blank lines are ignored.
#
# URLs are IMMUTABLE per-release links (Temurin resolves `latest/17` to
# jdk-17.0.21+9 as of 2026-11-17; the pin is the versioned link, not `latest`).
# sha1 values from Maven Central are recorded in the comment line above each
# jar for cross-reference; the script gate is the sha256 below.
